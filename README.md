# Replication pack

Which Relationship Gives Way? Asymmetric Dependence and the Allocation of
Adjustment

Everything needed to reproduce the paper's results, self-contained.

## Contents

```
scripts/        01-30, run in numeric order (see scripts/README.md)
raw/            Correlates of War source data, as downloaded (unmodified)
data/           intermediate panels the scripts build from raw/ — included
                so you don't have to re-run everything to inspect them,
                but every one of them is fully regenerated by scripts 01-05
results/        every model object, figure, and result table the paper
                cites, as produced by this exact code — use these to check
                your own re-run against the reported numbers
logs/           console output captured from the original run of each script
session_info.txt   R version and package versions used to produce the
                results in results/
```

Two derived files exceed GitHub's 100MB per-file limit and are not tracked
in this repository (see `.gitignore`): `data/tie_trade.csv` and
`results/hazard_models.rds`. Both are fully regenerated by scripts 01 and
04 respectively — nothing in `results/` that the paper cites depends on a
file that isn't in this repo.

## How to reproduce

Requirements: R (developed under R 4.6.0; see `session_info.txt`) and the
packages listed there (`dplyr`, `readr`, `tidyr`, `igraph`, `sandwich`,
`lmtest`, `survival`, `purrr`, `readxl`).

```bash
cd replication_pack        # working directory must be this folder
for f in scripts/*.R; do Rscript "$f"; done
```

Or run scripts individually, in numeric order — each one only depends on
outputs from earlier-numbered scripts (all already present in `data/` and
`results/`, so you can also run any single script standalone). All paths
inside the scripts are relative to this folder (`raw/...`, `data/...`,
`results/...`); no path editing is needed, but the working directory must
be `replication_pack/` itself when you invoke `Rscript`.

Running the full pipeline overwrites `data/` and `results/` in place with
freshly regenerated versions. Everything is deterministic.

## What maps to what in the paper

`scripts/README.md` lists all 30 scripts with a one-line description and
the paper section/table/figure each one feeds. Start there. Scripts 29
and 30 document a genuine analytical correction made during review
(described in the paper's Appendix C.2): script 29's approach is kept on
disk, unused, rather than deleted, consistent with how every other
discarded check in this project's history is treated.

## Related project

This project is a follow-up to *Two Paths Out of Imbalance* (prepared for
JCR), which models how signed interstate triads resolve via dissolution
or realignment and treats trade volume as a stabilizing control. Its own
replication pack is at
https://github.com/thomas-u-grund/two-paths-out-of-imbalance. This
project asks a different question — not whether trade *interdependence*
stabilizes a triad, but whether *asymmetric* trade dependence determines
which relationship absorbs an adjustment that has to happen somewhere.
